## Rejected / deferred
- **Rejected:** storing state only in chat; `checkpoint.md`; giant bootstrap Story; automatic release of a ready Epic; Release nested under Epic; treating self-review as independent; embedding enterprise specialist implementations in the core orchestrator; the separate local versioned PoC instruction packages in decision 024 are an explicit demonstration exception.
- **Deferred:** greenfield bootstrap; corporate skill catalog and identity infrastructure; Jira/Teams integration; incomplete-Epic release planning; production deployment; unverified cross-host portability.

## Remaining open design work
- Host catalog installation and cross-host invocation beyond the checkout-based CLI.
- Story/Release schemas and production rollout beyond the sequential engineering slice.
- FR/AC/TC references and test-to-requirement traceability without duplicated authorities.
- Concurrent ID allocation, migration and compatibility policy.
- Production distribution and specialist-skill compatibility beyond the implemented local pinned catalog.

**Handover:** Codex should first read the complete [specification](../specification.md), identify inconsistencies and propose the smallest working increment, before implementation.

## Governance correction addendum — 2026-10-29

**028 [D/P]** Newly advanced Analysis cycles activate governance0.1 through versioned
work-track metadata, preserving all historical cycles and baselines. Observable prototype
limitations require explicit human consent within the existing revision-bound Design
approval; uncertainty acknowledgement and generic Design approval are insufficient.

historical migration. See [Engineering governance](../engineering.md#governance-corrections-contract-01).
